# Nativo 기능 명세 (UI/UX 개선 기준 문서)

> 작성일: 2026-07-06 · 대상: `apps/web` (Next.js 14 App Router)
> 목적: 전 페이지 UI/UX 개선 작업 전, 현재 구현된 모든 기능·화면 구성·입력/선택 사항·상태와 추가 예정 기능을 정리한 기준 문서.

---

## 1. 제품 개요

- **Nativo** — "Speak your way to native." 영어 / 스페인어 / 일본어 3개 언어 학습 플랫폼.
- **단일 사용자 로컬 모드**: 로그인 화면 없음. 루트(`/`) 진입 시 플래시카드 보유 여부로 분기
  - 카드 있음 → `/dashboard`
  - 카드 없음 → `/onboarding`
- UI 언어는 한국어(`<html lang="ko">`), 학습 콘텐츠는 선택한 학습 언어.
- 백엔드: Supabase(로컬) + OpenAI(AI 기능) + 외부 소스(Project Gutenberg, YouTube/yt-dlp).
- 스키마에는 **5단계 Phase 시스템**(users.current_phase 1~5, phase_completions)이 정의되어 있으나 UI는 아직 미구현 (→ 7장 추가 예정 기능).

### 기술 스택 (UI 관련)

| 항목 | 내용 |
|---|---|
| 프레임워크 | Next.js 14 (App Router, 서버 컴포넌트 중심) |
| 스타일 | Tailwind CSS + shadcn/ui 스타일 토큰 (`primary`, `secondary`, `accent`, `muted`, `destructive`, `success`) |
| 공용 UI 컴포넌트 | `components/ui/` — `Button`, `Card`, `Input`, `Label`, `Badge`, `states`(ErrorBanner 등) |
| 아이콘 | 이모지 위주 (🔊 ✏️ 🎧 ✅ 등) + lucide-react 일부 |
| 레이아웃 관례 | `AppHeader` + `main.container max-w-xl~2xl py-10` (읽기 뷰어만 `max-w-6xl`) |

### 공통 컴포넌트/패턴

- **AppHeader** (`components/AppHeader.tsx`): sticky 상단 바.
  - 좌: "Nativo" 로고 → `/dashboard`
  - 중앙: 가로 스크롤 내비 8개 — 플래시카드 / 청크 / 쉐도잉 / AI 대화 / 읽기 / 번역가 / 영작 일기 / 뉘앙스 (현재 경로 `bg-accent` 강조)
  - 우: "설정" 링크
  - ⚠️ 메뉴가 8개라 좁은 화면에서 가로 스크롤 발생 — 모바일 내비 개선 포인트
- **SupabaseNotice**: Supabase 미설정 시 모든 페이지가 이 안내 카드 하나로 대체됨.
- **환경 미설정 안내**: OpenAI 키 없으면 AI 기능은 503 → "OpenAI 키가 설정된 환경에서만 동작합니다" 인라인 안내(기능별 저장은 가능).
- **HeartToggle** (♥): 학습 카드/사전 어디서든 단어·청크를 "내 것"으로 담기/빼기.
- **빈 상태(Empty state)**: Card 안 가운데 정렬 이모지 + 설명 + 행동 버튼 패턴.
- **에러**: `ErrorBanner`(인라인 배너) 또는 빨간 텍스트. 토스트 시스템 없음.
- **로딩**: 버튼 라벨 교체("저장 중…") 방식. 스켈레톤/스피너/`loading.tsx` 없음 → 서버 페이지 전환 시 무피드백 구간 존재 — 개선 포인트.

## 2. 페이지별 기능 명세

각 페이지는 **화면 구성 / 입력 사항 / 선택 사항 / 동작·상태** 순으로 정리.
"입력 사항"은 사용자가 타이핑/업로드하는 값, "선택 사항"은 버튼·탭·토글로 고르는 값.
🚧 표시는 아직 미구현이며 추가 예정인 항목(상세는 7장).

### 2.1 `/` — 루트 (app/page.tsx)

- 화면 없음. 온보딩 완료 여부(카드 보유)로 `/dashboard` 또는 `/onboarding` 리다이렉트만 수행.

### 2.2 `/onboarding` — 온보딩

- **화면 구성**: 학습 언어 선택 카드 3개(국기 이모지 + 라벨, 선택 시 `ring-primary`) → "시작하기" 대형 버튼.
- **입력 사항**: 없음.
- **선택 사항**:

  | 항목 | 선택지 | 기본값 | 필수 |
  |---|---|---|---|
  | 학습 언어 | 영어 🇺🇸 / 스페인어 🇪🇸 / 일본어 🇯🇵 (3택1) | english | ✅ |

- **동작·상태**: `completeOnboarding(language)` 서버 액션 → `/dashboard` 이동. 저장 중 "준비 중…", 실패 시 빨간 텍스트.
- ⚠️ 레벨(CEFR)·이름은 온보딩에서 받지 않음(설정에만 존재) — 온보딩 확장 검토 포인트. 🚧 레벨테스트 도입 시 온보딩 흐름에 포함 검토.

### 2.3 `/dashboard` — 대시보드 (홈)

- **화면 구성**: 인사말 헤더("안녕하세요, {이름}님" + 언어 라벨 + 🔥 스트릭 N일) + "📊 통계" 버튼 → **오늘의 코스** 3단계 체크리스트 카드("N/3 완료" 카운터).
  1. 🎧 쉐도잉 — 오늘 쉐도잉 영상 활동 여부로 완료 판정
  2. ✏️ 플래시카드 복습 — 복습 도래 카드 0장이면 완료, 아니면 "복습할 카드 N장"
  3. ✅ 오늘의 루틴 — 루틴 태스크 전부 체크 시 완료
  - 각 행: 완료✓/번호 원형 배지 + 이모지 + 라벨 + 설명 + (다음 할 일에만) "지금" 배지 + `›`
- **입력/선택 사항**: 없음 (전부 이동 링크).
- **데이터**: 복습 도래 수, 총 카드 수, 스트릭, 오늘 쉐도잉 여부, 오늘 루틴 완료 목록 (Promise.all 5쿼리).
- ⚠️ 읽기·AI 대화·번역가·일기·뉘앙스는 홈에 진입점 없음(헤더 내비뿐) — 발견성 개선 포인트.

### 2.4 `/learn/flashcards` — 플래시카드 학습

- **데이터 로직**:
  - 복습 도래 카드(next_review_at 지난 것, 오래된 순)를 회당 학습량(쿠키 설정, 기본 60)까지 로드.
  - 부족분은 내장 단어 DB(`data/word-db/*.json`)에서 레벨 ±1 새 단어 자동 투입(flashcards 테이블에 insert).
  - SRS: `gradeFlashcard(card, choice)` 서버 액션 (ReviewChoice: good/hard 등).
  - 🚧 **출제 범위 선택(추가 예정)**: 전체 / 하트(♥ 내 단어)만 / 랜덤 / 특정 레벨만 / 특정 키워드만 등 — 현재는 "복습 도래 + 자동 투입" 단일 방식. 학습 시작 전 범위 필터 UI 자리 필요. (→ 7.1)
- **화면 구성**: 제목 + "내 단어 사전" 버튼 → 모드 탭(segmented) + "n / N" 진행 → 카드 영역(♥ 하트 우상단) → 진행 버튼.
- **입력 사항**:

  | 모드 | 입력 | 검증/비교 |
  |---|---|---|
  | 주관식 | 단어 텍스트 1줄 | 공백 트림 + 소문자 비교(`norm`). 빈 값이면 "확인" 비활성 |
  | 받아쓰기 | 들은 단어 텍스트 1줄 | 동일 |

- **선택 사항**:

  | 항목 | 선택지 | 기본값 | 비고 |
  |---|---|---|---|
  | 학습 모드 | 뒤집기 / 객관식 / 주관식 / 받아쓰기 | 뒤집기 | 모드 전환해도 진행 위치 유지. 객관식은 카드 4장 미만 시 비활성(툴팁) |
  | 객관식 보기 | 뜻 4지선다 (정답 + 오답 3, 셔플) | — | 선택 즉시 정답 초록/오답 빨강, 재선택 불가 |
  | ♥ 내 단어 담기 | 토글 | curated 카드는 꺼짐 | 진행과 무관, 언제든 |
  | 발음 듣기 | 단어 영역 탭 / 🔊 버튼 | 카드 등장 시 자동 1회 | Web Speech TTS |

- **모드별 인터랙션**:
  - **뒤집기**: 상단 단어 탭=발음(TTS), 하단 탭=뜻 보기/숨기기(발음기호·한국어 뜻·영영 뜻·예문). 뜻을 봐야 "다음" 활성화. 카드 등장 시 자동 발음 1회.
  - **객관식**: 단어 제시 → 뜻 4지선다 → "다음"(정답=good, 오답=hard).
  - **주관식(production)**: 뜻 제시 → 단어 입력 → "확인" → ✓정답/✗정답(정답 노출) → "다음".
  - **받아쓰기(dictation)**: TTS 자동 재생 → 들은 단어 입력. 🔊 재청취 버튼.
  - 뒤집기는 "good" 고정 채점(무평가 진행에 가까움).
- **상태**: 완료 화면(✅ N개 학습 완료 + 다시/홈으로), 빈 상태(🎉 오늘 학습 끝 + 사전 링크), 저장 실패 ErrorBanner.

### 2.5 `/learn/flashcards/dictionary` — 내 단어 사전

- **화면 구성**: 내가 담은(♥) 단어 목록(WordDictionary) + 전체 단어 DB 탐색(AllWordsList).
- **입력 사항**: 검색어 1줄 — placeholder "단어·뜻 검색…" (단어/뜻 부분 일치).
- **선택 사항**: ♥ 담기/빼기 토글, 영구 삭제(`deleteWord`).
- **상태**: 목록 없음 문구와 검색 결과 없음 문구 분리.

### 2.6 `/learn/chunks` — 청크(표현) 학습

- 플래시카드와 동일 골격. 회당 기본 30개, Leitner 방식(`isChunkDue`), 부족분 chunk-db에서 레벨 ±1 자동 투입.
- **입력 사항**: 주관식 — 표현 텍스트(트림 + 소문자 + 연속 공백 1개 정규화 후 비교).
- **선택 사항**:

  | 항목 | 선택지 | 기본값 | 비고 |
  |---|---|---|---|
  | 학습 모드 | 뒤집기 / 객관식 / 주관식 / **뉘앙스** | 뒤집기 | 객관식=뜻 4개↑, 뉘앙스=표현 4개↑ 필요 |
  | ♥ 내 청크 담기 | 토글 | manual 소스만 켜짐 | |

- **카드 필드**: 표현, 한국어 뜻, 상황(situation), 뉘앙스 설명, 예문 1·2, 카테고리 배지, 레벨.
- **채점**: 뒤집기=무채점(null), 나머지 정답/오답 boolean → `gradeChunk`.
- 완료 화면 → "내 청크 사전" 유도.
- 🚧 출제 범위 선택은 플래시카드와 동일 패턴으로 적용 검토. (→ 7.1)

### 2.7 `/learn/chunks/dictionary` — 청크 사전 + 생성기

- **화면 구성**: 내 청크 목록 + 전체 청크 목록(AllChunksList) + **ChunkGenerator**(AI 생성).
- **입력 사항 (ChunkGenerator)**:

  | 항목 | 형식 | 검증 | placeholder |
  |---|---|---|---|
  | 상황/주제 | 텍스트 1줄 | 2자 이상(미만 시 생성 버튼 비활성) | "예: 호텔에서 체크인할 때" |

- **선택 사항**: 생성된 청크 일괄 저장("전부 저장" 버튼). 레벨은 별도 선택 없이 **프로필 레벨 자동 사용**.
- **외부 의존**: `/api/chunks/generate` (OpenAI 필요).

### 2.8 `/learn/shadowing` — 쉐도잉 목록

- **화면 구성**: 제목/설명 → AddVideoForm → 영상 카드 그리드(2열: 썸네일, 제목, 이어보기 위치, 완료 배지).
- **입력 사항**:

  | 항목 | 형식 | 검증 | placeholder |
  |---|---|---|---|
  | YouTube URL | `type=url` 1줄 | 빈 값 제출 무시. 서버에서 youtube.com/youtu.be 파싱, 실패 시 에러 문구 | "YouTube 링크 붙여넣기 (youtube.com / youtu.be)" |

- **동작**: 추가 성공 시 곧바로 플레이어 페이지로 이동. 서버가 제목·썸네일 자동 조회.
- **빈 상태**: "위에 YouTube 링크를 붙여넣어 첫 영상을 추가하세요."

### 2.9 `/learn/shadowing/[id]` — 쉐도잉 플레이어

- **화면 구성**: YouTube 임베드 플레이어 → 컨트롤 바 → 자막 리스트 / 자막 입력 영역.
- **선택 사항 (플레이어 컨트롤)**:

  | 항목 | 선택지 | 기본값 |
  |---|---|---|
  | 재생/일시정지 | 토글 | 일시정지 |
  | 시킹 | -3초 / +3초 버튼 | — |
  | 배속 | 0.5 / 0.75 / 1 / 1.25 (4택1) | 1 |
  | A-B 구간 반복 | A 지점 지정 → B 지점 지정 → 반복 / 해제 | 꺼짐 |
  | 자막 줄 반복 | 자막 줄 클릭=해당 구간 이동 + 줄 단위 반복(loopCue) | — |

- **입력 사항 (자막)** — 3가지 방법:

  | 방법 | 형식 | 검증/처리 |
  |---|---|---|
  | 자동 가져오기 | 버튼 1회 | 서버 yt-dlp 실행. videoId 11자 정규식 검증. 503=yt-dlp 미설치 안내, 404=자막 없음 안내 |
  | 직접 붙여넣기 | SRT/VTT/타임스탬프 텍스트 textarea | `parseSubtitles` 파싱, 최대 5000줄 저장 |
  | 파일 업로드 | .srt/.vtt 파일 선택 | 파일 내용을 textarea에 로드 후 동일 파싱 |

- **자동 저장**: 마지막 재생 위치(last_position_sec), 누적 시청 시간. 자막이 없으면 자막 편집 모드로 시작.

### 2.10 `/learn/roleplay` — AI 대화 (역할극) 목록

- **화면 구성**: 카드 그리드(2열). 첫 카드 ✏️ "커스텀 상황 만들기"(점선) + 정적 시나리오 9종.
  - 시나리오: 카페 주문 / 공항 수하물 / 환불 요청 / 취업 면접 / 스몰토크 / 식당 컴플레인 / 병원 진료 / 호텔 체크인 / 연봉 협상 (이모지 + 카테고리 배지 + 미션 문구).
- **입력/선택 사항**: 시나리오 카드 선택만.
- OpenAI 키 없으면 amber 안내 카드(목록 열람만 가능).

### 2.11 `/learn/roleplay/[scenarioId]` · `/custom` — 역할극 채팅

- **커스텀 설정 폼 (`/custom`)**:

  | 항목 | 형식 | 검증 | placeholder |
  |---|---|---|---|
  | AI가 맡을 역할(상황) | 텍스트 1줄 | 필수(트림 후 1자↑) | "예: 까다로운 부동산 중개인" |
  | 나의 목표(미션) | 텍스트 1줄 | 필수 | "예: 월세를 5만원 깎아서 계약하기" |

  - 두 값 모두 있어야 "대화 시작" 활성. OpenAI 키 없으면 시작 불가 + 안내. 시작 후 상단에 상대/미션 요약 박스 고정.
- **채팅 입력 사항**:

  | 방법 | 조건 | 비고 |
  |---|---|---|
  | 텍스트 입력 | 항상 | 1줄 Input + 전송 |
  | 🎤 음성 입력 | 브라우저 SpeechRecognition 지원 시 | 중간 인식 결과가 입력창에 실시간 반영, 재탭으로 중지 |

- **선택 사항**:

  | 항목 | 선택지 | 기본값 |
  |---|---|---|
  | 🔈 음성 응답(autoSpeak) | 켜기/끄기 토글 (TTS 지원 브라우저만 노출) | 켜짐 |
  | 종료 & 피드백 | 버튼 | — |

- **동작·상태**: AI 응답에서 미션 완료 토큰 감지 시 자동 종료 흐름. "종료 & 피드백" → FeedbackPanel(분야별 점수 + 표현별 평가, 모국어 해설). 피드백 작성 중 로딩 문구.

### 2.12 `/learn/reading` — 읽기 (문서 목록)

- **화면 구성**(위→아래): 제목/설명 + PDF 업로드 버튼 → 내 문서 그리드 → 이어 읽기 그리드(최대 4) → 검색 폼 → Gutenberg 책 그리드(24권).
- **입력 사항**:

  | 항목 | 형식 | 검증 | 비고 |
  |---|---|---|---|
  | 검색어 `q` | GET 폼 텍스트 1줄 | 없음(빈 값=인기순) | placeholder "제목·작가 검색 (예: Tom Sawyer)" |
  | PDF 업로드 | 파일 선택 `accept=application/pdf,.pdf` | 서버 pdf-parse 추출 실패 시 에러 문구 | 업로드 중 "변환 중…", 성공 시 뷰어로 자동 이동 |

- **선택 사항**: 책/문서 카드 클릭(뷰어 이동), 이어 읽기 카드(마지막 쪽으로 이동).
- **상태**: 검색 결과 없음 카드. 내 문서/이어 읽기 섹션은 데이터 있을 때만 노출.

### 2.13 `/learn/reading/[id]` — 읽기 뷰어 (Reader)

- id가 documents에 있으면 **내 PDF**, 아니면 **Gutenberg 책**(본문 다운로드 → 문단 기준 ~1800자 페이지 분할).
- **선택 사항 (본문 인터랙션)**:

  | 동작 | 결과 |
  |---|---|
  | 단어 클릭 | 사전 팝업: 자동 발음(TTS) + `/api/enrich` 뜻 조회(내장 사전→AI 폴백, 출처 라벨 "전체 사전"/"AI 검색") + ♥ 카드 담기 |
  | 텍스트 드래그(2자↑) | 선택 영역 위 "번역하기" 플로팅 버튼 → 우측 번역 패널로 전달 |
  | 문장 클릭 | 번역 대상 문장 선택 |
  | 이전/다음 쪽 | 페이지 이동(`?p=`), 이동마다 진행률 upsert |

- **입력 사항**: 번역 패널 — 한국어 번역 텍스트 → "AI 평가"(정확/자연/뉘앙스 점수) → 번역 세션 저장.
- **동작·상태**: `?p` 없이 열면 마지막 읽던 쪽으로 자동 리다이렉트. 마지막 쪽 "끝까지 읽었어요 🎉". 본문 추출 불가 시 안내 카드. 단어 클릭 vs 드래그 충돌은 "선택 중이면 사전 안 띄움"으로 처리.

### 2.14 `/learn/translate` — 번역가 모드

- **입력 사항**:

  | 항목 | 형식 | 검증 |
  |---|---|---|
  | 원문(학습 언어) | textarea 5줄 | 트림 후 2자 이상 |
  | 내 번역(한국어) | textarea 5줄 | 트림 후 1자 이상 |

  - 두 조건 충족 시에만 "AI 평가"/"저장" 활성.
- **선택 사항**: "AI 평가"(선택적 — 평가 없이 저장 가능), "저장".
- **동작·상태**: 평가 = 정확/자연/뉘앙스 3축 점수 + 총점 + 합격 여부 + 피드백. 503 시 "평가 없이 저장 가능" 안내. 저장 성공 초록 배너.
- **지난 번역** 목록(최근 10건): 날짜, 총점(합격 시 success 색), 원문/내 번역.

### 2.15 `/learn/journal` — 영작 일기

- **입력 사항**:

  | 항목 | 형식 | 검증 |
  |---|---|---|
  | 일기 본문 | textarea 7줄(세로 리사이즈 가능) | 저장: 1자↑ · AI 첨삭: 5자↑ |

  - 실시간 단어 수 카운터 표시.
- **선택 사항**: "AI 첨삭"(선택적) → 첨삭 결과 확인 후 "저장". 첨삭 없이 바로 저장 가능.
- **동작·상태**: 첨삭 결과 카드 = 총평 + 교정 목록(원문 취소선 빨강 → 교정 초록 + 이유). 교정 0건 "잘 썼어요! 🎉". 저장 시 입력·첨삭 초기화 + 초록 배너. 하루 한 편 저장(entry_date 기준).
- **지난 일기** 목록(최근 20건): 날짜, 단어 수, 본문, AI 총평, 첨삭 N건.

### 2.16 `/learn/nuance` — 뉘앙스 퀴즈

- **입력 사항**: 없음.
- **선택 사항**:

  | 항목 | 선택지 | 비고 |
  |---|---|---|
  | 퀴즈 시작 / 새 퀴즈 | 버튼 | `/api/nuance/quiz`로 문제 세트 생성(OpenAI 필수) |
  | 답안 | 표현 4지선다 | 선택 즉시 채점·해설, 재선택 불가 → "다음" |

- **동작·상태**: 진행("n / N" + 현재 점수) → 완료 화면("N문제 중 M개 정답!"). 시작 전 인트로 카드(🎯). 문제 수·난이도 선택 옵션 없음 — 개선 여지.

### 2.17 `/learn/routine` — 오늘의 루틴

- **화면 구성**: "← 대시보드" 링크 + 체크리스트.
- **선택 사항**: 태스크 체크/해제 (4개 고정, 언어 공통):

  | 태스크 | 권장 시간 | 바로가기 |
  |---|---|---|
  | 플래시카드 복습 | 15분 | /learn/flashcards |
  | 청크 복습 | 15분 | /learn/chunks |
  | 유튜브 쉐도잉 | 15분 | /learn/shadowing |
  | 원서 읽기 | 15분 | /learn/reading |

- **동작**: 전부 완료 시 스트릭 적립(daily_logs). 루틴 30일 = Phase 1 졸업 조건(`STREAK_GOAL_DAYS = 30`, 코드에 정의만 존재).
- ⚠️ 이 페이지만 AppHeader 없음 + `neutral-*` 색상 하드코딩 — 디자인 통일 필요.

### 2.18 `/learn/stats` — 학습 통계

- **화면 구성**: 스탯 카드 6개(현재 스트릭[강조] / 최장 스트릭 / 누적 학습 시간 / 학습한 날 / 단어 완료·전체 / 청크 완료·전체) + 진행 바 카드(단어·청크 숙지율).
- **입력/선택 사항**: 없음(조회 전용). 기간 필터·언어 전환 옵션 없음 — 개선 여지.
- **데이터**: flashcards.repetitions, chunks.review_count, daily_logs 집계(`lib/stats`).
- ⚠️ 시계열 차트 없음(누적 수치만).

### 2.19 `/settings` — 설정

- **입력 사항**:

  | 항목 | 형식 | 검증 | 저장 위치 |
  |---|---|---|---|
  | 플래시카드 회당 학습량 | 숫자 입력 | 5~200 클램프, 반올림, 기본 60 | 쿠키(기기별, 1년) |

- 🚧 **설정 세분화(추가 예정)**: 학습 기록 관리, 단어장 관리, "레벨 ±1 위주 학습" 사용 여부 토글, 레벨테스트, 테마(다크 모드), TTS 보이스 설정 등 — 현재 4개 항목뿐이라 섹션 그룹핑(프로필/학습/모양/음성) 구조로 재설계 필요. (→ 7.1)

## 5. 클라이언트 공용 기능

- **TTS** (`lib/tts.ts` `speak(text, language)`): Web Speech API. 플래시카드·읽기 사전·받아쓰기·역할극 음성 응답에서 사용. (Google Cloud TTS 서버 프록시로 교체 예정 주석 있음)
- **음성 인식** (`lib/speech.ts`): 역할극 음성 입력. 브라우저 지원 시에만 버튼 노출.
- **세션 크기** (`lib/session-size.ts`): 쿠키 기반 회당 학습량 (min 5 / max 200 클램프).
- **단어/청크 내장 DB** (`data/word-db/*.json`, chunk-db): 레벨별 큐레이션 콘텐츠 자동 공급.

## 6. UI/UX 개선 시 고려할 현재 상태 요약

### 일관성
- 페이지 골격은 대체로 `AppHeader + container max-w-xl~2xl py-10 + 제목/부제`로 통일되어 있으나, **루틴 페이지만 헤더 없음 + neutral 색상 하드코딩**.
- 색 토큰은 정의되어 있지만 amber 배너(`border-amber-300 bg-amber-50`) 등 하드코딩 예외 존재.
- 아이콘이 전부 이모지 — 톤 통일(아이콘 시스템 도입) 여부 결정 필요.
- textarea가 공용 컴포넌트 없이 페이지마다 수동 스타일(일기·번역가) — Textarea 컴포넌트화 필요.

### 피드백/상태
- 라우트 전환·서버 액션 대기 중 시각 피드백 없음 (`loading.tsx`, 스켈레톤, 토스트 부재).
- 에러는 인라인 텍스트/배너 방식으로 페이지마다 표현이 조금씩 다름(빨간 p / ErrorBanner / amber 카드).
- 완료/빈 상태 카드 패턴은 있으나 일러스트 없이 이모지 1개 + 텍스트.

### 내비게이션
- 헤더 메뉴 8개 + 설정 — 모바일에서 가로 스크롤. 기능 그룹핑(학습/콘텐츠/AI) 또는 하단 탭/햄버거 검토 여지.
- 대시보드 "오늘의 코스"는 3개 기능만 노출 — 나머지 5개 기능의 홈 진입점 부재.
- 사전(단어/청크), 통계, 루틴은 서브 페이지로만 존재.

### 반응형
- 그리드는 `sm:grid-cols-2` 수준의 단순 반응형. 읽기 뷰어(2단, max-w-6xl)의 모바일 레이아웃 검토 필요.
- 다크 모드 미구현 (라이트 단일 테마).
- **추후 모바일(앱)로도 구현 계획 있음** → 이번 웹 UI 개선을 모바일 우선(mobile-first) 기준으로 진행 권장.

### 접근성
- 이모지 버튼에 `aria-label` 일부 존재(🔊, 음성 입력 등)하나 전반적 점검 필요. 키보드 내비게이션·포커스 스타일 미점검.

### 7.1 확정/근거 있는 예정 기능

| **Phase 시스템 (1~5단계)** | `users.current_phase`, `phase_completions` 테이블, routine.ts "설계서 Phase 1" 주석 | 5단계 학습 단계 진급 시스템. 루틴 30일 스트릭(`STREAK_GOAL_DAYS=30`)이 Phase 1 졸업 조건. 대시보드/통계에 Phase 진행도 UI 필요 예정 |

| **Google Cloud TTS 서버 프록시** | lib/tts.ts 주석 | 현재 브라우저 Web Speech(품질·언어 편차 큼) → 서버 TTS 교체 예정. 발음 듣기 버튼 UX(로딩·재생 상태)와 TTS 보이스 설정에 영향 |
| **study_stats 활용** | 스키마만 존재 | 상세 학습 통계 집계 테이블 — 통계 페이지 고도화(시계열 등)에 사용 예정 |

### 7.2 제안 후보 (문서 작성 시점 제안 — 확정 아님)

현재 구현의 빈틈에서 도출한 후보. UI/UX 개선과 함께 검토할 것.

- **온보딩 확장**: 레벨(CEFR) 선택 또는 레벨테스트 + 이름 입력을 온보딩으로 이동(현재 설정에만 있음).
- **대시보드 전 기능 진입점**: 오늘의 코스 외 나머지 5개 기능(읽기·AI 대화·번역가·일기·뉘앙스)의 카드/바로가기.
- **뉘앙스 퀴즈 옵션**: 문제 수·주제·난이도 선택(현재 옵션 없음).
- **통계 고도화**: 주간/월간 시계열 차트, 기능별(읽기/쉐도잉/역할극) 활동 통계, 언어 비교.
- **읽기 뷰어 옵션**: 글자 크기/줄 간격/폰트 설정, 페이지 크기(현재 1800자 고정) 조정.
- **쉐도잉 녹음 비교**: 내 발음 녹음 → 원본과 비교 재생(현재 듣고 따라 말하기만).
- **알림/리마인더**: 루틴 미완료 시 리마인드(현재 없음).
- **토스트/전역 피드백 시스템**: 저장·담기(♥)·에러의 일관된 피드백.
- **PDF 외 포맷**: EPUB/TXT 업로드(현재 PDF만).
